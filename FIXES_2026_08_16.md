### 2. ⚠️ Quota Check Error - "Impossible de vérifier votre quota"

**Problem:** Error message appearing when checking quota in chat.

**Root Cause:** 
- `loadProfile()` function in `src/lib/quota.ts` was throwing errors without fallback
- Happens when Supabase profile creation fails

**Fix Applied:**
- Enhanced error handling in `loadProfile()`
- Added fallback to default quota (0 used, "free" plan) if profile creation fails
- Added console logging for debugging

**Impact:**
- Chat should now work even if profile creation temporarily fails
- Error will retry on next request instead of blocking entirely

## Troubleshooting

### Chat still shows "Impossible de vérifier votre quota"
1. Check `.env.local` has valid Supabase credentials
2. Check Supabase `profiles` table exists
3. Run: `npm run dev` to restart with new code
4. Check browser console for detailed error

### Tebex checkout shows 404
1. Verify package IDs in `.env.local` are correct
2. Check IDs against creator.tebex.io dashboard
3. Try full URL: `https://asexcel.tebex.store/package/{ID}?custom=test`
4. If still 404, IDs are wrong or store is not live

### Tariffs page still shows empty badge
1. Clear browser cache (Cmd+Shift+R or Ctrl+Shift+R)
2. Rebuild: `npm run build`
3. Restart dev server: `npm run dev`
